How this map works

  1. Temperature background: one ECOSTRESS ISS pass (~70 m land-surface temperature), mosaicked from same-timestamp tiles and clipped to the Chicago data-center cluster. The pipeline processed 22 nights; this image is the max-coverage pass (2025-07-31), not a multi-night collage. If those tiles fail, the street map stays and the status line says temperature tiles are unavailable.
  2. Data center dots: Chicago-area sites from the project list. Click a dot for name and address.
  3. AOI risk: optional buffer scores (off by default). Not the first-look story.
  4. DC Δ vs controls: each data-center buffer compared with matched nearby areas at the same timestamps. Positive means the site ran warmer.
  5. Before vs after opening: where an opening date is known, popups split the record into pre-open and post-open windows.
  6. Partial coverage: ECOSTRESS is a swath sensor. A hard edge means that pass missed part of the cluster, not a broken map. Sites still get an irregular night-by-night series on nights they were observed.
